Representation-control analysis outputs for the revised Evoscope manuscript

This archive contains the output files generated by the representation-control analyses added during revision of the manuscript “A Minimal Regulatory Spatial Model for Emergent Multicellular Organization in Dissipative Environments.”

The files correspond to the held-out seed baseline-control analyses reported in Supplementary Table S1 and the latent temporal prediction controls reported in Supplementary Table S2.

The Supplementary_Table_S1/ directory contains the CSV files used to report the held-out baseline and autoencoder comparison metrics.

The Supplementary_Table_S2/ directory contains the CSV file used to report the latent temporal prediction results.

Additional files in the archive include intermediate prediction outputs, autoencoder training histories, merged covariate datasets, morphology metadata, saved latent representations for each simulation seed, the temporal prediction configuration file, and the trained autoencoder checkpoint used for the latent temporal prediction analysis.

The corresponding analysis scripts and documentation are available in the GitHub repository:

https://github.com/lunanfoldomics/evoscope/tree/main/analysis/representation_controls

Because autoencoder training involves stochastic initialization and backend-dependent numerical variation, re-running the analyses may produce minor numerical differences, especially for the autoencoder prediction-head and autoencoder latent z8 + ridge outputs. The files included in this archive should be considered the manuscript reference outputs used for the revised Supplementary Information.
